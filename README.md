# java-playground


## Java 25
### features
- Unnamed Variables and Patterns
- Module Import Declarations

#### Unnamed Variables and Patterns
- Unnamed variables apply to local variables
    - for loops
    - try-with-resources
    - exception parameters
    - lambda expressions
    - switch blocks
    - records
- Unnamed variables do not apply to instance variables

#### Module Import Declarations
- import module java.base;
